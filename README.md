# dot-movies

A Next.js application for tracking and managing your movie watchlist and watched movies, with integration for importing data from Letterboxd.

## Features

- Browse and view movie details
- Maintain a personal watchlist
- Track watched movies
- Import data from Letterboxd via CLI tools
- TVDB integration for movie information

## Getting Started

First, install dependencies:

```bash
pnpm install
```

Then, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## CLI Tools

The project includes several CLI tools for data management. See [docs/README.md](docs/README.md) for detailed documentation on available tools.

## Commands

- **Build**: `pnpm build`
- **Dev**: `pnpm dev`
- **Lint**: `pnpm lint`
- **Lint fix**: `pnpm lint:fix`
- **Format**: `pnpm format`
- **Type check**: `pnpm check`
